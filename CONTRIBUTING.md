# Contributing

Issues are welcome: device compatibility reports help the most (see the issue templates).

Pull requests need the [Contributor License Agreement](CLA.md) once. A bot asks on your first pull request; reply
with the sentence it gives. The Project is GPL-3.0 and may also be offered under a commercial license, and the CLA
is what allows that for contributed code. You keep the copyright in your work.

Before a pull request: `firmware/test/run.sh` (firmware and UI tests) and a firmware build should pass.
